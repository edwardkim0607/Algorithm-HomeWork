핵심 의사코드 · HWP 캡처용

실제 HTML의 우선순위 큐 기반 탐색 흐름을 간략화한 의사코드입니다. 동일한 목표 정점 G에서 종료하며, 음수 가중치는 사용하지 않습니다.

① Dijkstra g(n) 기준
Dijkstra(G, S, G_goal):
  dist[*] ← ∞; dist[S] ← 0
  PQ.push((0, S)); closed ← ∅

  while PQ ≠ ∅:
    (d, u) ← PQ.popMin()   // 최소 g
    if u ∈ closed or d ≠ dist[u]: continue
    closed.add(u)
    if u = G_goal: break

    for each (v, w) ∈ Adj[u]:
      alt ← dist[u] + w
      if alt < dist[v]:
        dist[v] ← alt; parent[v] ← u
        PQ.push((dist[v], v))

  return dist[G_goal], parent

dist는 시작점에서의 최단 거리 추정값, PQ는 최소 힙, parent는 경로 복원용 직전 정점.

② A* Search f(n) = g(n) + h(n)
AStar(G, S, G_goal, h):
  g[*] ← ∞; g[S] ← 0
  PQ.push((h(S), 0, S)); closed ← ∅

  while PQ ≠ ∅:
    (f, d, u) ← PQ.popMin() // 최소 g+h
    if u ∈ closed or d ≠ g[u]: continue
    closed.add(u)
    if u = G_goal: break

    for each (v, w) ∈ Adj[u]:
      alt ← g[u] + w
      if alt < g[v]:
        g[v] ← alt; parent[v] ← u
        PQ.push((g[v]+h(v), g[v], v))

  return g[G_goal], parent

h는 목표까지의 추정 잔여 비용. 이 예제의 일관적인 휴리스틱을 사용하여 최적 경로를 구합니다.

동점 처리: 작은 g 우선, 이어서 정점 이름의 알파벳순. 이 의사코드는 우선순위 비교의 전체 동점 처리를 간략화했습니다. 정점 최대 8개, 가중치 비음수, 유효한 일관적 h를 전제로 합니다.

실험 설계 및 안전한 해석

정점 8개 · 시작 S · 목표 G · 무방향 그래프 · 비음수 가중치 · 종료: G가 우선순위 큐에서 제거될 때. 동점은 g가 더 작은 정점, 그다음 알파벳순으로 선택.

A*는 h(v) = α (|xᵥ−xG|+|yᵥ−yG|)를 사용합니다. 0 ≤ α ≤ 1이고 각 간선 가중치는 그 간선의 맨해튼 거리 이상이므로 h는 일관적이며, 최단 경로를 보장합니다.

확장 정점 수가 적어도 실제 실행 시간이 반드시 같은 비율로 감소하지는 않습니다. 휴리스틱 계산 비용과 자료구조 구현 방식의 영향을 받습니다.
